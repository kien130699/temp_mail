# Notification Dashboard & Message Hub

A lightweight, modern web dashboard for monitoring incoming notifications, service alerts, and confirmation tokens in real-time.

## Features
- 🚀 **Realtime Notification Stream**: Instant updates via Server-Sent Events (SSE).
- 🎨 **Glassmorphism Web UI**: Clean, dark-mode responsive dashboard.
- ⚡ **RESTful API**: Standard JSON endpoints for message integration.
- 🗄️ **SQLite Local Cache**: High-speed indexing (< 3ms response).

## Quick Start
```bash
pip install -r requirements.txt
python3 app.py
```
Open `http://localhost:3000` in your browser.
